Safety and portability

  • The default operation prints a boot packet and performs no host execution.
  • Write-side brain announcements require --announce.
  • Host execution requires --exec and uses an argument array without a shell.
  • No provider credential, personal endpoint, personal path, or implicit permission bypass belongs in source.
  • Machine-specific adapters are opt-in and removable.

How this evolves

This diagram is a versioned projection, not permanent ontology. Future evidence may move an adapter, split a policy, or introduce another Work. The stable identity is the outcome: Agent Zero wakes with current state, holds human intent, and coordinates through explicit external contracts.
