Best principles

Separate the intent-holder from the execution substrate

An agent identity remains portable when state, model execution, workspace management, capabilities, and project policy are external contracts. A useful coordinator composes those systems; it does not absorb their source merely because it calls them.

Evidence: the 2026-07-30 Agent Zero extraction reduced six warehouse scripts to one core identity/boot outcome, one optional adapter, and three explicitly deferred or reclassified modules.
